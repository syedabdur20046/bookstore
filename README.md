# 📚 Bookstore Analytics with SQL

## 📌 Project Overview

**Bookstore Analytics with SQL** is a data analysis project built using **MySQL** to analyze bookstore sales, customers, inventory, revenue, marketing spend, and purchasing behavior.

The project uses relational database concepts, SQL queries, aggregations, joins, CTEs, date functions, and business analytics techniques to generate useful insights from bookstore data.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze book sales and revenue
* Identify best-selling books
* Monitor low-stock books
* Analyze customer purchasing behavior
* Perform RFM (Recency, Frequency, Monetary) analysis
* Identify returning and churned customers
* Calculate Average Order Value (AOV)
* Analyze revenue by city and genre
* Calculate Customer Lifetime Value (CLV)
* Compare marketing spend with customer revenue
* Analyze monthly sales trends
* Calculate inventory value
* Identify books purchased by the same customers

## 🗂️ Database Structure

The project contains four main tables:

### 1. `books`

Stores information about books.

| Column    | Description         |
| --------- | ------------------- |
| `book_id` | Unique book ID      |
| `title`   | Book title          |
| `genre`   | Book genre          |
| `price`   | Book price          |
| `stock`   | Available inventory |

### 2. `customers`

Stores customer information.

| Column        | Description                |
| ------------- | -------------------------- |
| `customer_id` | Unique customer ID         |
| `name`        | Customer name              |
| `city`        | Customer city              |
| `signup_date` | Customer registration date |

### 3. `orders`

Stores customer purchase information.

| Column        | Description               |
| ------------- | ------------------------- |
| `order_id`    | Unique order ID           |
| `customer_id` | Customer reference        |
| `book_id`     | Book reference            |
| `quantity`    | Number of books purchased |
| `order_date`  | Date of purchase          |

### 4. `marketing_spend`

Stores marketing expenditure associated with customers.

| Column         | Description           |
| -------------- | --------------------- |
| `spend_id`     | Unique spend ID       |
| `customer_id`  | Customer reference    |
| `spend_amount` | Marketing expenditure |
